# The House — a haunted-house story, told by a ghost

Hacktoberfest Week 4 (DEV Open-Source AI Challenge), theme "Ghost in the
Machine". A tiny interactive fiction game: you walk a haunted house, and
every room is written by an open-weight model (Gemma) as you walk it. Five
rooms, then the way out. No two visits are the same.

## How it works

- `index.html` — the whole game UI. No build step.
- `server.py` — the whole server. Python standard library only, no pip
  dependencies. Game state lives in the browser; the server is stateless.
- Rooms are generated by Gemma — locally through Ollama, or in the public
  demo through a hosted OpenRouter endpoint (`google/gemma-3-12b-it`). If
  the model is unreachable or its output is unusable, a seeded template
  room is returned instead and labelled as such, so the game never
  dead-ends. Model proposes, code disposes — the same rule as the
  Week 3 entry.
- The UI labels every room honestly: "written by Gemma" or "fallback".

## Run it

```sh
ollama serve
ollama create gemma3-1b-local -f Modelfile   # first time only, from the local GGUF
OLLAMA_MODEL=gemma3-1b-local python3 server.py
# open http://localhost:8080
```

Or hosted, with no local model:

```sh
OPENROUTER_API_KEY=... python3 server.py
```

Environment variables: `OLLAMA_BASE` (default `http://localhost:11434`),
`OLLAMA_MODEL` (default `gemma3:1b`), `OPENROUTER_API_KEY` (if set, the
hosted endpoint is used instead of Ollama), `OPENROUTER_MODEL` (default
`google/gemma-3-12b-it`), `PORT` (default `8080`).

## Contest categories honestly claimed

- **Gemma** (featured): rooms and the ending are generated by Gemma, an
  open-weight model, when the model is up. Fallback rooms are labelled.
- **Render** (featured): the public demo runs on Render (see render.yaml).
- No other category is claimed. Nothing here uses a partner product, and
  the write-up will not pretend otherwise.
